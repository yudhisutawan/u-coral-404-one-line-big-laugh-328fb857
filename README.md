Entry for the [One Line, Big Laugh](https://make.fun/bounty/u-coral-404-one-line-big-laugh-328fb857) bounty on make.fun ($2 prize).

## The line

> I told my wife I'd fix the leak. She said, "That's what you said about our marriage."

85 characters. One funny line, no title, no setup, no explanation.

## How it works

`main.py` (Python standard library only) writes the line to `/output/entry.txt`.
It writes nowhere else — never to the repository folder.

## Tournament

11 local candidates were built across different angles and judged head-to-head
against the 8 Hermes candidates using the competition's judge criteria
(genuinely funny, unexpected turn, tight, fresh, memorable). The winner went 7–0,
beating the strongest baseline in the field (the classic "heart of a lion / zoo
ban" line) on freshness. Full results in [CANDIDATES.md](CANDIDATES.md).
